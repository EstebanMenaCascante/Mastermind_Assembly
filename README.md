# Mastermind_Assembly

## Descripción del proyecto

Este proyecto consiste en el desarrollo del juego **Mastermind (Toros y Vacas)** utilizando lenguaje Ensamblador x86 de 16 bits.

El objetivo es aplicar conocimientos de programación en Ensamblador, manejo de registros, memoria, interrupciones del BIOS y gráficos VGA.

## Estado del proyecto

> 🚧 **En fase inicial de desarrollo.**

Actualmente, el proyecto se encuentra en sus primeras etapas de planificación e implementación.

Este README se actualizará progresivamente conforme se incorporen nuevas funcionalidades, mejoras y documentación.

## Tecnologías y herramientas

- **Lenguaje:** Ensamblador x86 de 16 bits.
- **Entorno de ejecución:** DOSBox.
- **Modo gráfico:** VGA 13h.
- **Entrada de datos:** Teclado mediante interrupciones del BIOS.
- **Herramientas de desarrollo:** Pendientes de definir.

## Funcionalidades previstas

- [ ] Pantalla de presentación y menú principal.
- [ ] Tres niveles de dificultad.
- [ ] Generación pseudoaleatoria del código secreto.
